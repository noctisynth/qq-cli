# macOS 只读挂载监管

文档编号：CHECK-124。日期：2026-10-24。关联：SPEC-008、TASK-006。起点：b29b464。

image/attach以m2日志调用独立工作进程，宿主注册私有入口；固定hdiutil只读、不浏览、不自动打开及精确挂载点。父端在工作进程启动后重新复核原guard，发送唯一许可字节1，继续按原截止/guard观察。工作进程以非阻塞stdin等待许可/观察EOF或额外输入，镜像与空挂载目录必须匹配继承FD及私有权限；副本FD设置CLOEXEC。挂载前核对系统不存在既有镜像/挂载点并重核原描述符。调用者不能指定工具或任意附加参数。

父端取消只关闭管道，不杀监管者；监管者复用有界系统命令内核，取消时仅回收原直接Child并确认退出。监管进程退出码不证明diskimages辅助服务停止，也不证明已卸载；未知退出保持未知。m2独立验证允许元数据转换、实际只读挂载、媒体代次及Source所需读取能力，不以attach返回码直接发布完成。

监管4项测试（含夹具入口）通过：父EOF、guard撤销、截止回收直接命令；强制结束原创owner进程后，仍存活的监管者回收命令；不认识的监管退出码不能证明清理。夹具在exec后记录PID，以避免把exec代次变化误认为进程退出；不操作QQ或其他会话。日志6项测试（含夹具入口）通过，新增独立进程在Pending后的锁争用拒绝及强制退出恢复Unknown、不重放/不接受另一请求。
