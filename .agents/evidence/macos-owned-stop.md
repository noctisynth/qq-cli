# macOS 原拥有运行停止与恢复

文档编号：CHECK-132。日期：2026-10-25。关联：SPEC-008、TASK-006。起点：cb278e7（含前一阶段保留的停止草稿）。

## 实现与证明边界

macOS `napcat stop` 已接入独立平台用例，输出沿用原Stopped契约。stop/journal维护p2及原成员父索引，members处理冻结/收敛/原代次终止，session明确组合原生命周期锁、状态锁身份、完整实例/安装快照、j2来源及d2回执。run按认证/发布/声明分模块；原根audit token在首次派发时保存，不在恢复时重新采纳当前exec代次。v3实际启动输入绑定原继承范围；旧服务记录仍可只读恢复，但不补造停止或当前兼容权威。

初次停止先认证原完整部署，成员只能由原父身份前后复核授予，SIGSTOP/SIGKILL分别先持久保存原audit目标及一次意图。暂停原拥有成员后收敛，未知/已脱离而缺少历史归属的候选保留，不以同文件或进程组认领。没有数值PID/killpg回退；恢复不重发未知信号。最后重新读取完整部署内容、观察全部原成员退出和受限文件集无活候选，先保存完成p2再确认stopped。完成确认可独立恢复；跨启动会话不向当前PID发信号。失败可能保留已暂停的原成员；这不是断电、不可中断内核操作或恶意同用户竞态的完成保证，也不宣称系统代理服务已关闭。

## 定向验证

15项停止用例通过。原创C应用经过实际复制、加固、签名、独立执行限制、s1派发及j2发布，验证完整停止、重复完成复用、确认中断恢复、原副本已不存在时的完成确认，以及保留安装/凭据/数据。没有使用真实QQ作为夹具。

成员用例验证换进程组不丢失已经证明的直接后代；同映像陌生进程和未记录孤儿不被暂停/终止；原根已退出且受限库存为空可无信号完成；相同PID/映像的exec代次不能重新授权。内存效果边界注入保存后中断，分别证明未知暂停和未知终止不重发，后续仅靠原退出观察完成。签名组合验证Pending/Unknown原s1可凭原j2清理而不重放启动；缺声明或audit目标的旧j2、错密钥、安装变化拒绝。不同boot的合成签名记录即使使用当前PID也不向其发信号。不同boot为签名夹具模拟，不是本次实际系统重启实验；信号阶段注入也不等于穷尽真实CLI突然死亡或断电矩阵。

6项原生进程用例通过，包含原身份恢复、退出/exec、父关系、受检文件集合、文件变化/链接/截止拒绝。新增反例保留一个已进入等待状态、随后可执行文件被移除的无关合成进程，枚举仍找到专用文件集的两个候选，并独立确认该无关进程仍活着；受检文件自身缺失则拒绝观察。首轮完整门禁发现夹具在exec后、Rust/libtest就绪前删除文件可能使其提前退出；补明确就绪握手后，全组通过，原失败用例再连续5次通过。

## 系统查询核查

本机验证组合为原生Apple Silicon、macOS 27.0 / Darwin 27.0.0、SDK 27.0、rustc 1.98.1；不扩大为最低系统版本或其他设备支持承诺。只读聚合观察发现，同UID列表可包含PROC_PIDTBSDINFO明确返回ESRCH的终止槽位，以及仍存活但proc_pidpath返回ENOENT的映像；没有输出或保存无关PID、路径或进程内容。

Apple公开XNU源码的本次只读快照用于核对SDK行为，获取日期同上；链接为main，以下内容摘要固定本次观察，不是对未来main或特定系统版本的额外保证：

- [libproc.c](https://raw.githubusercontent.com/apple-oss-distributions/xnu/main/libsyscall/wrappers/libproc/libproc.c)，SHA-256 `5c8a771427e04c5e1d55c4cdf5a077f3b52c5be4a091683b970084bfdda76df2`。
- [proc_info.c](https://raw.githubusercontent.com/apple-oss-distributions/xnu/main/bsd/kern/proc_info.c)，SHA-256 `557092f14fbad3341100f59e0391d2e812c54b79a7404c89b2af97471ad67082`。proc_pidpathinfo_internal从text vnode解析路径并重查链接；实现仅在受检文件仍保持原链接/身份时排除ENOENT映像，不将其视为退出。
- [proc_listpidspath.c](https://raw.githubusercontent.com/apple-oss-distributions/xnu/main/libsyscall/wrappers/libproc/proc_listpidspath.c)，SHA-256 `5b5810da2d11db49ba4cd2a9192c19a2b626dfed17b4cac05e32baf8e0e2b36a`。该便利枚举在逐进程错误时跳过，故没有把其空结果单独升级为停止完成证明；新集合观察使用有界同UID活出生集合，并对其余访问/截断/范围错误拒绝完成。

上游源码仅存临时目录，没有复制到本次分发内容；提交的C适配仅为原创窄SDK调用。
