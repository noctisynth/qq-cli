# 停止前持久版本维护意图

文档编号：CHECK-027。状态：有界离线验收。更新：2026-10-19。
关联：SPEC-004、RFC-0003、TASK-002、CHECK-024、CHECK-026。

CHECK-026留下p1完成至g1认领前的恢复窗口：当时只有显式update保留目标，普通start可能按源安装准备。现在v1签名保存源完整实例/安装、目标安装及update或rollback动作，源实例/run固定索引先写，Registry可选maintenanceIntents当前标记提交后才允许停止。只索引已写但源完整快照未变时，begin可恢复同一标记；停止后已知标记/索引丢失或冲突拒绝，不推断或补建维护计划。

当前标记每实例最多一项；Registry旧数据缺省为空，空集合不写出。start/restart对待维护源返回VERSION_MAINTENANCE_PENDING及原维护操作，不先检查源包或访问账号API；新建另一个实例不替代原操作。卸载在原生命周期/状态锁内核对维护签名，保护停止后仍未认领的新目标。状态注册表标记本身也是已知签名材料，密钥丢失时不因签名目录缺失而生成替代密钥。

g1的可选maintenanceReference绑定原v1签名及源/目标安装，旧g1 schema1/2无该字段仍可读，不伪造旧操作来源。新run登记和当前标记退役使用同一Registry提交；写入失败时源与当前标记保留，已有认领计划恢复。g1可只读查询当代维护动作，普通后续重启不继承旧动作。明确remove停止实例会在注销提交中退役当前标记，历史索引与签名记录保留，不让根注册表积累历史运行列表。

职责拆分为version_intent的领域/发布、journal的固定索引与HMAC读写、transition的代次绑定；update编排、g1提交、启动门禁、卸载/注销和签名密钥恢复各保留原边界。不新增用户可选模式、任意端点或信任参数。

首批3项意图测试通过：停止前意图不改变源实例或调用停止；同源/目标/动作复用，动作冲突拒绝；目标卸载及旧版本启动阻止；停止后缺索引或当前标记不恢复；Windows共享只读句柄阻止标记发布后，源未变时恢复原签名。随后补充未知源阶段在写签名前拒绝、仅Registry标记仍拒绝替代密钥，以及g1提交阻断/原子退役的验证。
