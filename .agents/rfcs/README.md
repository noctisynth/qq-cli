# 需求方案工作流

文档编号：RFC-0000。状态：Active。更新：2026-10-24。

RFC 回答为什么做、为谁做、做到什么程度：记录问题、目标、非目标、用户行为、取舍、验收要求和决定依据。
详细接口、数据结构、并发/恢复机制进入关联 Spec；事实引用 FACT，验证引用 CHECK，进度引用 TASK。

Draft 是未采纳方案；Accepted 是已采纳需求；Rejected 保留不采用理由；Superseded 指向替代方案。
Accepted 不代表技术机制已冻结或功能已验收。只有需求/取舍变化才修订 RFC，不逐次追加测试结果。
普通已授权实现细节无需新 RFC。编号四位递增；旧提案保留编号并明确替代关系。
