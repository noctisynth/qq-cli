# 产品基线

文档编号：SPEC-001。状态：Active。更新：2026-10-16。
依据：用户在项目建立前的需求澄清和本次初始化指令。

## 已确认目标

- 用户正常使用官方 QQ 窗口时，Agent 仍可后台调用，不抢占鼠标、键盘或输入焦点。
- 用户和 Agent 使用同一个个人账号会话；不通过创建独立官方机器人身份替代。
- 尽可能复用本机 QQ 安装；不依赖 LiteLoaderQQNT。
- 优先研究独立加载器复用原版 NapCat 产物；没有必要时不维护上游 fork。
- 提供适合本地 Agent 使用的 CLI；具体命令和技术栈尚未确定。

## 本轮授权范围

建立本地 Git、Semifold 和可移植上下文，参考既有项目的文档分层，使用 Agent 审查并本地提交。
不包含产品实现、QQ 重启、DLL 加载、真实会话或消息操作、远端仓库创建和推送。

## 决策边界

用户此前因风险排除注入式 Framework，后续要求研究不依赖 LiteLoader 的独立加载路径。
这不构成对运行真实注入实验的授权，也不能推导为用户接受所有 Hook 机制；需在实施设计中明确。
技术可行性与协议、账号风险分别记录；更换加载器不会自动消除风险。

## 后续验收方向

在明确实验范围后验证：官方窗口保留、仅一个目标会话、只读接口工作、用户输入焦点不变、
双方消息事件一致、退出和重连行为可控。真实发信验证需具备明确目标和内容。
当前均未完成；源码架构推断不替代这些验收。
