# 已安装目标的更新编排

文档编号：CHECK-026。状态：已安装目标接合有界离线验收。更新：2026-10-19。
关联：SPEC-004、RFC-0003、TASK-002、CHECK-020、CHECK-024、CHECK-025。

start_engine/version保持单一生命周期锁：先核对目标版本安装、QQ元数据及精确兼容，再凭原Job停止原run，核对停止后完整快照，使用reserve_version_run生成/恢复目标代次并复用共享launch。原快照已被后继替换时不停止当前run，仅按原p1/g1恢复。目标已是当前安装时复用有界start；签名准备快照推进后仍可恢复同代，starting/unknown不重放。新run账号/进程观察清空，目标登录仍走原AUTH_REQUIRED/status及受检OneBot身份链路。

app/runtime/version负责固定版本和唯一已安装目标选择，existing适配器共用原签名权威、原生预检和响应；没有添加公开绕过参数。缺目标返回INSTALLATION_NOT_FOUND及符合napcat.install输入Schema的下一步，未知版本拒绝，均先于凭据及停止。napcat.update共享start/restart领域响应Schema。自动目标来源准备尚未接入，此处不是完整版本维护交付。

复核发现目标预检与g1认领之间，卸载原先仅用状态锁，可能删除目标后才让更新发现失败。卸载现在先获取同一生命周期锁、再获取状态事务，与启动/停止/更新保持顺序；导入只取得状态事务且不反向等待生命周期锁。该同步保护本工具调用之间的目标存续，不承诺阻止任意外部文件写入，最终输入/材料绑定仍保留。

26项runtime_store/runtime_stop定向测试通过：原创Rust三参数等待/回环服务分别作为旧/目标版本替身，以独立安装快照与原版本配置运行，原Job在更新后成员清空；保留实例ID、切换安装/新run、缓存旧安装为回滚目标；旧快照重复复用、同目标不停止或换秘密；目标准备中断后用原内部键恢复，不再次取消；未知结果不增加Job。公开CLI用原创临时会话验证缺目标/未知版本不改登记、不调用消息API、不停止原进程，并验证安装指引Schema。
