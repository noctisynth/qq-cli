# CLI 最小实现清单

文档编号：TASK-002。状态：Ready for implementation，未开始。更新：2026-10-17。
依据：SPEC-004、PLAN-001、RFC-0002。下列勾选只表示实际实现和必要验证完成。

## M0 命令骨架与工具链

- [ ] 建立 Rust 单 binary crate、edition 2024、Cargo.lock 和 qq-cli 可执行入口；固定经验证的工具链及最低编译器版本。
- [ ] 按 RFC-0002 配置 clap、serde/serde_json、reqwest blocking 与 sha2；核验最小 features。
- [ ] Cargo.toml 建立后核对 Semifold Cargo 解析配置并迁移版本来源，移除遗留 package.json，不产生双版本真值。
- [ ] 建立参数解析、离线 help/version、JSON 包装与退出码；先不连接真实 QQ。
- [ ] 加入 cargo fmt/clippy/test/build 检查，使用 --locked 验证依赖固定；通过子进程调用原生 CLI。

完成依据：合成输入下帮助、未知命令和 JSON 错误均符合契约；无隐式网络请求。

## M1 配置与固定 HTTP 客户端

- [ ] 实现显式配置文件及 endpoint/token 环境来源；凭据不接受命令行参数，配置覆盖顺序确定。
- [ ] 限回环字面地址、显式端口、无代理/无重定向、截止时间、响应体上限和固定 action 表。
- [ ] 校验 HTTP 与 OneBot envelope、字段类型及无损整数标识；统一脱敏错误，测试超过浮点精确范围的有效整数不被取整。

完成依据：本地假服务覆盖鉴权失败、200 业务失败、断流、超时、重定向、无效 JSON 及超限；无真实凭据夹具。

## M2 只读命令与会话门禁

- [ ] 实现 doctor/status/self、上游版本检查和期望账号校验；doctor 不试发消息。
- [ ] 实现 message get 与指定私聊最近历史，限制数量，不自动翻页/下载或展开媒体。
- [ ] 输出字符串标识、明确时间单位和文本/未知段结构；不假设消息 ID 可跨上游重启使用。

完成依据：离线或错账号时消息 action 调用数为零；六个上游 action 中本阶段只用读接口。

## M3 有界文本发送

- [ ] 实现互斥的 text/text-file/stdin、UTF-8/大小校验和显式目标；只构造 text 消息段。
- [ ] 实现请求键、规范载荷摘要、私有发送记录的独占创建与落盘状态；记录失败不发信。
- [ ] 实现 accepted/rejected/pending/unknown、重复键缓存结果、载荷冲突与 SEND_UNKNOWN，禁止自动重试。

完成依据：假服务计数证明同键跨进程最多一次请求；模拟应答丢失、进程中断及落盘失败不导致第二次发送。

## M4 交付与有界回归

- [ ] 补齐用户配置/命令/JSON/错误/未知发送处置文档，所有示例仅使用合成内容。
- [ ] fmt/clippy/test/release 构建通过后检查原生交付与 Cargo 源码包白名单；不带上游、运行材料、私有配置或 Agent 上下文。
- [ ] 在新的明确账号、目标和文本授权下执行 CLI 本身的只读与单次发送回归；不得重用旧实验的单次发送授权。
- [ ] 记录窗口/接口对应、读写结果和短时焦点；如无新真机授权，只交付离线验证结果并标注未回归。

完成依据：用户文档与实际帮助/输出一致，工作区可复现构建，真实回归状态如实记录，不承诺长期兼容。

实时事件、群聊、媒体、联系人搜索、多实例管理、QQ 启停及加载器均为后续候选，不是 M0 至 M4 的前置任务。
用户文档使用 patch:chore；产品代码按实际 feat/fix 等建立 changeset，纯 Agent 上下文不建立。
