# Agent 托管 NapCat 运行环境

文档编号：RFC-0003。状态：Draft，托管目标已确认，机制待验证。更新：2026-10-17。
关联：SPEC-001、SPEC-004、PLAN-001、TASK-002、FACT-002、CHECK-005。

## 问题与目标

用户要求尽量不介入，由 Agent 完成准备、配置和运行。仅连接用户手工维护的端点无法覆盖这一目标。
产品增加运行环境管理层，Agent 调用一个 CLI 即可从环境检查进入就绪状态，随后完成业务操作。
正常有效登录态下无需用户手工配置端口、复制密钥、打开 WebUI 或启动服务；QQ 要求身份确认时返回明确阻塞。
这不表示绕过 QQ 登录、设备验证、UAC 或账号风控，也不改变保留官方窗口和同会话操作的目标。

## 候选架构

qq-cli runtime 管理器 → 原版 Framework 原生入口 → 桌面 QQ/NapCat → 类型化 HTTP/WS → 业务命令。
不 fork、不自研加载器，仍复用官方 QQ 安装，不以 Shell 无头实例替代共享桌面会话。
默认走 managed profile，external profile 保留连接已有合规实例的能力，不能对外部实例假定所有权。
业务命令先执行有截止的 ensure-ready；仅做必要准备、幂等启动和就绪检查，不在每次调用重装或重启。

运行命令候选：runtime inspect/prepare/ensure/status/stop/restart/update/rollback；auth status/resume。
prepare 管理私有版本目录及清单，优先复用已验证材料；下载前验证来源、许可、版本、长度和摘要，安全解压，
不执行下载脚本、不修改 QQ 安装，不将来源公开等同于授权。许可未解决则报告阻塞，不静默接受条款。
托管不要求将上游产物打进本项目发布包。

配置自动生成回环 HTTP/WS、随机凭据、独立 WebUI 管理凭据及状态目录，探测端口冲突后选择可用端口并持久登记。
不扫端口接管未知实例；不读取/覆盖其他实例配置。凭据优先本地用户级受保护存储，环境引用保留给 external 模式。
密钥不通过命令参数、URL、stdout 或 Agent 上下文传递；管理 API 仅内部白名单，和消息 API 权限分别处理。
启动方式、启动前/登录前配置文件、WebUI 控制面及快速登录接口必须按固定产物验证，不能照搬 Shell 文档参数。

运行注册表保存版本/摘要、启动实例标识、进程创建时间、受管进程树、端点和期望账号，不只保存 PID。
跨 CLI 进程加锁保证只启动一次，启动返回须以正确实例的版本、身份及 HTTP/WS 就绪为证据。
CLI 退出不结束 QQ，恢复不以“杀全部 QQ”实施。外部实例不主动停止；受管实例也是用户窗口，
用户活跃时不自动重启/升级，显式维护操作检测活跃状态及副作用并可返回 RUNTIME_BUSY。
已有普通 QQ 不能因此直接接管；先报告 NOT_ATTACHED，可按策略新开受管实例，不能自动终止或改造原窗口。
新开实例还须核对同账号冲突，不能挤掉用户当前会话以满足就绪。

优先复用已有登录态或经验证的快速登录；状态为 starting、login_required、verifying、ready、degraded、stopped、blocked。
扫码/验证码/设备验证必须报告 AUTH_REQUIRED 和可操作的下一步，保存检查点让 auth resume 继续；
Agent 可以自动获取挑战状态，但不能承诺凭空完成用户身份确认，不收集账号密码或自动换账号绕过限制。
启动/登录可能出现窗口及焦点变化，须单独测量；稳态 API 不抢焦点的目标不能外推为启动零影响。

短暂 API 故障先有界等待与重连，不能以重启替代所有恢复；unknown 写入状态跨重启保留且禁止重发。
更新固定目标版本、显式维护窗口、配置/状态迁移及回滚；不跟随 latest 自动改变 QQ/原生兼容性。
无需为了上述管理先引入常驻守护进程；若跨进程启动和监测不足，再以证据评估可选监督进程。

## 验收与待决项

- 验证原版启动参数、QQ 定位、多实例/同账号冲突、配置隔离和快速登录能力；静态入口存在不代表全部支持。
- 断言两个并发 Agent 不重复启动、退出 CLI 不关 QQ、PID 重用不误杀、外部实例不被停止。
- 冷启动、有效登录态、登录过期、端口冲突、错误账号、升级/回滚、未知写状态恢复均有确定结果。
- 测试用户操作期间的恢复策略及启动/登录焦点，不能让故障修复抢占用户日常输入。
- 所有实际启动、登录及真实会话验证另有具体授权；本轮仅设计与本地检查/提交。

本 RFC 的具体启动/控制面机制尚未冻结；不能据此实现真实注入或宣称无人登录能力已验证。
