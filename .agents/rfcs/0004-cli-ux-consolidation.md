# CLI 语义、职责与调用成本

文档编号：RFC-0004。状态：Accepted。更新：2026-10-24。
技术契约：PLAN-001、SPEC-004。验收：TASK-002。

## 原则

按领域对象和任务职责组织命令，不以命令数量最少为目标。共享机制不要求合并公共语义。
减少重复配置、无意义前置调用及冗余输出；保留真实作用域、unknown、gap 和安全重试信息。

## 职责与范围

| 命令族 | 需求边界 |
|---|---|
| contact list/get | 好友发现和用户资料，不以最近聊天限制范围 |
| group list/get/members | 所属群、群资料和成员；这些读取命令不写入，群管理另按RFC-0009设任务 |
| conversation list/get | 最近会话及可观察元数据；query 不扩展为全量好友/群搜索，不创建关系或标记已读 |
| message history/search | JSON 分页读取和范围检索，不因 output 参数进入文件任务 |
| message export | 独立文件导出、续写和覆盖保护；stdout 只给摘要，不承诺全量归档 |
| message send/reply | 新消息与引用回复各自独立；共享载荷校验及防重，reply 从引用推导目标 |
| status/doctor | 当前状态/诊断原因，不强制每次先后调用 |

同名返回候选；已知目标或消息引用可以直接操作，不强制重复发现。
受检直接API与新增领域任务并存，范围见RFC-0009/SPEC-009；不能以通用入口取代领域任务或改变原list/get查询职责。
单实例自动选择，多实例明确选择；不公开 profile/模式/预设账号绑定。
普通分页满足本次 limit 是成功；未完成页才用部分结果表达，不能混同全库完整性。
默认预算、命令参数、错误码及导出原子恢复机制统一在 PLAN-001/SPEC-004。

## 验收

查询范围不互换，reply 正确推导目标，export 能续写且不覆盖未知文件。
未知副作用不因重试重新执行；错误提供必要下一步；Codex/OpenCode 的任务闭环分别验证。
